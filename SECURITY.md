# Security policy

TrustSim-HITL is research software, not a safety-certified controller. Do not connect it to a real vehicle, robot or operational system.

Report security issues privately to the repository owner rather than publishing secrets, third-party exploit details or personal data in public issues. Never include API tokens, credentials, private endpoints or participant identifiers.

The current prototype has no network service. Future integrations require threat modelling, dependency review, input validation, secure logging and an explicit fail-safe strategy before use.
