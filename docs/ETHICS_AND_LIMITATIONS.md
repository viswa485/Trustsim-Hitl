Ethics, safety and limitations
===============================

The current project runs a simplified software simulation. It has no participant interface, participant data, physical vehicle / robot connection or validated VR environment.

Before human-participant research, obtain the applicable institutional ethics approval. Define participant information, informed consent, withdrawal, data minimisation, pseudonymisation, access controls and retention / deletion. Never commit identifiable participant data or raw recordings.

The model omits steering, road geometry, tyre dynamics, sensor noise and complex traffic. It must not control a real vehicle or robot. Results are not a safety case, certification evidence or estimate of real-world risk.

ISO/IEC 27001 / 42001 knowledge can inform governance but does not certify this software. A future assurance argument needs system boundaries, hazard analysis, threat modelling, requirements traceability, verification evidence and independent review.

Default feedback comes from a deterministic software proxy. It tests data plumbing only and is not human judgement or a substitute for a human-participant study.
