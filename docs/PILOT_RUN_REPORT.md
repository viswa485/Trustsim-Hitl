# Reproducible pilot run — seed 2026

## Run configuration

- Evaluation episodes: 100 paired scenarios per condition
- Seed: 2026
- Feedback source: synthetic_expert_proxy
- Human-subject data used: false
- Environment: simplified longitudinal-road software simulation

## Observed outputs

| Metric | Autonomous baseline | Scripted safety shield | Feedback calibrated |
|---|---:|---:|---:|
| Collision rate | 0.060 | 0.030 | 0.030 |
| Unsafe-step rate | 0.041 | 0.023 | 0.024 |
| Completion rate | 0.940 | 0.970 | 0.970 |

Additional outputs are available in the locally generated summary JSON and episode CSV. The command used was `PYTHONPATH=src python -m trustsim.cli run --episodes 100 --seed 2026 --output-dir results/run-100`.

## Interpretation limits

These are observed outputs from one deterministic software run, not scientific evidence of real-world safety or statistically generalisable improvements. The expert proxy is a scripted rule, not a person. Calibration labels are generated by that same rule, so similar behaviour between the safety-shield and feedback-calibrated conditions is expected. This does not demonstrate that human feedback improves an AI model.

Before making comparative claims, run multiple pre-specified seeds, quantify uncertainty, inspect scenario-level failures and review the design with a supervisor. A more realistic simulator and genuine human feedback are required for the intended research questions.
