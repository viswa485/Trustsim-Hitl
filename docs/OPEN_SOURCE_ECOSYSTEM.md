Open-source ecosystem
=====================

This is an original research scaffold. It references, but does not copy or vendor, upstream code or assets.

- CARLA: planned autonomous-driving simulator.
- Gymnasium: optional adapter source is present; install the rl extra to use it.
- Stable-Baselines3: optional dependency declaration; training is not implemented.
- CARLA ScenarioRunner: planned; verify release compatibility.
- CARLA ROS bridge: planned; not integrated.

Verify exact upstream version, licence, notices, platform and compatibility before reuse. Unity and Unreal Engine have separate publisher licensing terms. No simulator binaries or engine assets are included.
