# Project status — v0.1.0

Stage: early prototype / research scoping.

Implemented: seeded scenarios, simplified longitudinal-road environment, rule-based policy, deterministic software proxy, feedback provenance schema, JSONL persistence, linear calibration baseline, paired three-condition runner, CSV/JSON outputs, optional Gymnasium adapter source, tests and CI.

Not implemented: real human feedback, participant study, Unity/Unreal scene, VR interface, CARLA, ScenarioRunner, ROS 2, RL training, formal hazard analysis, safety case or certification.

Next: validate scenario coverage and repeated seeds, add uncertainty reporting, prototype a desktop review interface, then plan simulator and VR integration. This project is not a validated autonomous-driving simulator.
